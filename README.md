# Abdullah Birthday Website ♡

A cute, responsive six-page birthday website made with HTML, CSS, and JavaScript.

## Pages
- `index.html` — birthday landing page
- `story.html` — your story since 2022 and the next chapter
- `reasons.html` — interactive reasons I love you cards
- `memories.html` — photo and WhatsApp screenshot placeholders
- `letter.html` — a birthday letter
- `forever.html` — future wishes and a clickable surprise

## Preview on your computer
1. Download and unzip the folder.
2. Open `index.html` in Chrome or another browser.
3. Click the navigation links to explore all six pages.

## Add your own photos and WhatsApp screenshots
1. Put your image files in the `images` folder.
2. Open `memories.html` in a code editor.
3. Replace a `<div class="photo-placeholder"> ... </div>` block with an image tag, for example:
   ```html
   <img class="memory-image" src="images/our-photo.jpg" alt="Our favourite photo">
   ```
4. Change `our-photo.jpg` to the exact filename you uploaded. You can use the same method for screenshots.
5. For the main and final photo, replace the relevant placeholder in `index.html` and `forever.html`.

**Tip:** crop screenshots before uploading if you want to hide phone numbers, profile photos, or private messages.

## Publish with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `abdullah-birthday`.
2. Upload all files and the `images` folder from this project (not just the ZIP file).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait for GitHub to publish the site. The link will look like `https://YOUR-USERNAME.github.io/abdullah-birthday/`.
